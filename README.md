# Manisha & Neel — Wedding Invitation

A standalone mobile-first wedding invitation website.

## Run locally

Open `index.html` in a browser, or publish the full folder with GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository and upload every file in this folder, including `assets/`.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save. GitHub will provide the public invitation URL.

The countdown updates live toward **3 January 2027, 00:00 IST**.
